一键清理

分五个方向：空间（含软件更新残留）、注册表、启动项、计划任务、后台服务。每个方向都是「扫描 → 勾选 → 应用」：空间处理磁盘上的目录与安装包缓存；注册表只挑指向已经不存在的登记，正常装着的软件和游戏不会列出来；启动项和计划任务是全量列出，停用还是删除由你自己选；后台服务改启动类型或单独停掉。切标签不会丢掉已经扫出来的结果，动手前先写备份；每个列表左上角都有全选框，一次勾上再剔掉几只。

检测规则

这一页是判定口径的出处。软件按四层判定：环境基线 → 单项可用性 → 删除前预检 → 执行后核对；界面上每条「建议删除 / 不建议修改」都能在下面的出处表里找到对应依据。

① 环境基线

系统与内部版本—
管理员权限—
系统还原—
组策略—

② 单项可用性

路径是否存在不存在则不显示该项
是否重解析点是则跳过，避免误删扩散
进程 / 服务 / 主程序任一命中判为「在用」，不删
是否需要管理员DISM、HKLM 写入会标出

③ 删除前预检

路径白名单只允许已知清理根
系统关键目录一律拒绝
互斥与占用被占用者排入重启删除
留证删除清单 + 还原点（注册表改动另存备份）

④ 执行后核对

成功计数按实际删除的文件计
失败明细逐条记录，不影响其它项
待重启项单独统计，重启后生效
报告写入日志与清单文件

哪些东西永远不删

C:\Windows / System32 / WinSxS / 字体、Program Files 与 ProgramData 根目录、用户目录与桌面文档图片、驱动存储、在用软件的注册表键。这些路径即使被误选，也会在删除前被 Guard 拦下并记录原因。
